# note_counter
Esse código simula um caixa eletrônico, mostrando a quantidade mínima de notas para sacar um determinado valor

# funcionalidades

mostra notas de:
- 100
- 50
- 20
- 10
- 5
- 2
- e moedas de 1

# linguagem utilizada

- Python

# conceitos praticados

- Função
- if (condições)
- while (repetição)
- Divisão inteira (//)
- Operador módulo ("Resto de divisão" %)

# como executar

```bash
python3 countage.py
```
